## 2026-11-20 — M0 prototype `prototypes/m0-scan` (large-file scanning feasibility)

**Environment (not the reference machine):** Linux 6.18 cloud container, Intel Xeon @ 2.10 GHz,
4 vCPUs, 15 GB RAM, virtual disk. Rust 1.97.0, `--release`. Files generated by the prototype,
**warm page cache** (files had just been written), single run each. Peak RSS = Linux `VmHWM`
(includes file-backed pages for `mmap`). Treat as indicative only: Windows/NTFS and cold-cache
numbers will differ and are still to be measured.

Files: `100m.log` (100 MiB, 1.31 M CRLF lines), `1g.log` (1 GiB, 13.2 M lines),
`1g-long.txt` (1 GiB, **one line**, no line breaks; mixed ASCII/Latin-1/CJK/✓).

| Strategy | 100 MiB | 1 GiB | 1 GiB single line | Peak RSS (1 GiB) |
|---|---|---|---|---|
| 1 MiB chunked `read` + `memchr` newline count | 0.020 s (5.0 GB/s) | 0.190 s (5.4 GB/s) | 0.180 s | **2–3 MiB** |
| `mmap` + `memchr` | 0.012 s (8.1 GB/s) | 0.120 s (8.6 GB/s) | 0.130 s | 1026 MiB (file-backed, not private) |
| Chunked read + sparse index (every 1 024th line) | 0.030 s | 0.256 s (4.0 GB/s) | 0.144 s | **3 MiB** (12 920 entries) |
| `ropey::Rope::from_reader` (whole file in memory) | 0.170 s | 1.790 s (0.57 GB/s) | 2.043 s | **1182–1210 MiB** |

**Conclusions**
1. Building a sparse line index is fast enough (~4 GB/s warm) to run in the background without the
   user noticing for files up to a few GB; on cold storage it will be I/O-bound (NVMe ≈ 2–7 GB/s,
   SATA SSD ≈ 0.5 GB/s, HDD ≈ 0.15 GB/s). P-12 (< 1 s for 1 GB, warm) looks achievable.
2. Bounded chunk reading keeps memory flat regardless of file size — supports P-11.
3. Loading a whole-file rope costs ~1.15× file size in RAM and ~2 s per GB: acceptable for Normal
   mode sizes, unacceptable for Large/Extreme. This confirms the piece-tree-over-file-backed-source
   design rather than a rope over loaded text.
4. Pathological single-line files are not a scanning problem; they are a **layout** problem
   (see ARCHITECTURE §5.4).

Reproduce:
```bash
cd prototypes/m0-scan && cargo build --release
./target/release/m0-scan gen /path/1g.log 1024
./target/release/m0-scan index /path/1g.log
```
