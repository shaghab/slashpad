# SlashPad

**Less memory. More text.**

SlashPad is an open-source, native Windows 11 text editor written in Rust — Notepad's simplicity
with tabs, split views, multi-gigabyte files, crash recovery and Markdown preview, and without
telemetry, ads, accounts or background processes.

> **Status: Milestone 0 (architecture and feasibility).** There is no usable application yet.
> See [ROADMAP.md](ROADMAP.md) and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
